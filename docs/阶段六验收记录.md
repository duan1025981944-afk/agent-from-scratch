## 方法

1. **每条测试重开一次 `python main.py`**。同一个会话里技能正文已经在上下文里，
   模型不需要再调 `load_skill`，会把"不用触发"误记成"没触发"。
2. **期望先填好，跑之前不许改。** 事后判卷容易自我说服。
3. 每条记：调了哪个技能 / 第几圈调的 / 结论对不对。
4. 负对照跑完**立刻改回来**。

## 已知边界

- `read_file` 没有 offset/limit，大文件会被截尾（第 34 讲实测：`agent/skills.py` 尾部约 2,400 字符没进上下文）
- 技能的附带文件（`references/`）没做：`load_skill` 只读 SKILL.md
- 单次成功不等于稳定：同一条问法建议跑两三次，模型选路是概率性的
